# Artic9 Creative Agency — Next.js Official Website

A cutting-edge, high-converting digital agency website engineered in **Next.js 15 (App Router)** and modern **Vanilla CSS**, modeled after the structure of [Aiwa Digital](https://aiwadigital.com/) and powered by the authentic business data, metrics, and branding from the **Artic9 2025 Corporate Brochure**.

---

## 🌟 Key Architecture & Features

### 1. Aiwa Digital-Inspired Layout Patterns
- **Glassmorphic Sticky Header**: Frosted glass navbar with live scroll detection, direct quick-dial button, "Let's Talk" CTA, and a responsive hamburger trigger.
- **Slide-Out Offcanvas Drawer**: Full-screen sliding menu drawer with large typography navigation, company mission, direct email/phone buttons, office addresses, and social links.
- **High-Impact 2-Column Hero**:
  - Live pulse badge: `#1 Digital Marketing & Tech Agency in South India`.
  - Dynamic headline: *“We Help Brands Grow With Creative Power, High-Impact Tech & Results-Driven Marketing.”*
  - Dual action pill buttons: *“Explore Our Services”* and *“Book Strategy Call”*.
  - Floating metric cards (`1500+ Projects`, `07+ Years`).
- **Impact Metrics Deck**: Highlighting `1500+` Launched Projects, `250+` Notable Clients, `07+` Years of Industry Mastery, and `25+` In-House Gurus.
- **Interactive Services Matrix**: 8 full-spectrum service cards with category filters (*Branding & Creative*, *Web & Engineering*, *Marketing & Growth*, *Media & Production*), feature checkmarks, and hover image overlays.
- **Brand Story & Office Hubs (Split Section)**: Detail on Artic9's founding in 2019, Vision, Mission, Regional to Global delivery model, and offices in **Nagercoil (KKM Building)** and **Chennai (Nungambakkam)**.
- **Case Studies Showcase**: Spotlight on **GT Holidays** (Sangam Group of Hotels), **Pragrup Architecture**, viral **F&B Social Media Campaigns** (Drizzle Bistro & People's Dosa), and **Documentary Storytelling**.
- **Infinite Marquee & Client Matrix**: Infinite auto-scrolling ticker showcasing **Young Indians (Yi)**, **Toni&Guy Hairdressing**, **Titan World Nagercoil**, **BNI**, **YES**, **Arunachala Hitech**, **Rajan & Co**, etc.
- **Verified Client Testimonials**: Direct quotes from **Karthick Manikandan** (*Founder & MD, GT Holidays*) and **Parveen Mathew** (*Correspondent, Corpus Christi School*).
- **Tech Stack Deck**: Highlighting AWS, Node.js, Firebase, MySQL, MongoDB, Next.js, and TypeScript.
- **Knowledge Accordion (Growth Guide)**: Accessible, mutually exclusive HTML `<details>` accordions answering critical client questions with smooth animations and zero layout shift.
- **Interactive Project Planner Form**: Multi-select service chips, budget range selector, real-time feedback, and celebration confetti upon submission.
- **Comprehensive Agency Footer**: Multi-column directory, studio locations, contact details, social links, and copyright.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17+ or v20+)
- npm

### Running Locally

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Open in browser
http://localhost:3000
```

### Production Build

```bash
# Build the production bundle
npm run build

# Start the production server
npm start
```
